# Jeevan Pariyar — Cloud & DevOps Portfolio

A responsive static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Included
- `index.html` — portfolio content and sections
- `style.css` — responsive dark technical design
- `script.js` — mobile navigation menu
- No build tools or framework required

## Run locally
1. Download or clone this folder.
2. Open `index.html` in a browser.

For a local web server, run from this folder:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080`.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `jeevan-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Before publishing — personalize these items
Search `index.html` and replace:
- `https://www.linkedin.com/` with your LinkedIn profile URL
- `https://github.com/` with your GitHub profile and each project's actual repository URL
- `your.email@example.com` with your professional email address
- Update project descriptions with actual implementation details and outcomes

The experience and project summaries are drafted from details shared in conversation. Review every statement and edit anything that does not accurately represent your work. Avoid publishing confidential employer or client information.
